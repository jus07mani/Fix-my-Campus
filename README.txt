OFFLINE LEARNING PACK BUILDER

How to run
1. Extract this ZIP folder.
2. Open Offline_Learning_Pack_Builder in VS Code.
3. Open a terminal in that folder.
4. Run: python learning_pack.py
   On Windows you can also use: py learning_pack.py

Requires Python 3 with Tkinter. No additional pip packages are needed.

How to use
1. Enter a pack name and subject.
2. Click Add Files and select your notes, PDFs or other study files.
3. Enter study tasks, one per line.
4. Click Create Pack and choose where to save the ZIP.
5. Extract the created ZIP to access Study Files and Study_Checklist.txt.

Clear resets the form and selected file list.
The selected-files box is a display: editing its text does not remove files.
The app creates one subject pack at a time. It does not save unfinished projects.
Original study files remain in their existing locations.
